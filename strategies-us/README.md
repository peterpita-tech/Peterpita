# 策略選股 · 美股(VCP + 趨勢模板,免費資料)

線上版(每個交易日美股收盤後、台灣早上 7:20 左右更新):https://peterpita-tech.github.io/Peterpita/strategies-us/

資料:NASDAQ 代號表(目前市值 ≥ 3 億美元,約 3000 檔)+ Yahoo Finance 日線(還原權值)+ SEC EDGAR 季報。
回測引擎與台股共用(`../strategies/backtest.py`),大盤基準 SPY,成本估 0.05%(美股無交易稅)。

## 策略

| 策略 | 換股 | 選股 |
|---|---|---|
| **VCP 突破** | 每日檢查 | 趨勢模板 + 波動收縮 + 量縮後放量突破樞紐點;跌破 50 日均線或虧損 8% 出場,最多 20 檔 |
| **趨勢模板 RS 前 20** | 每月 | 符合趨勢模板 8 條件中,相對強度最高 20 檔 |
| 三頻率 RSI | 每週 | 同台股(ROE > 0) |
| 低波動 30 | 每月 | 日均成交額 > 500 萬美元中,60 日波動率最低 30 檔 |
| 風險調整報酬 前 15 | 每季 | 同台股(ROE > 5%、單季營收年增 > 0) |
| 本益成長比 PEG | 每月 | 營收動能向上中 PEG 最低 10 檔,停損 10%;美股無月營收,改用季營收 |
| 高波動 30(對照組) | 每月 | 60 日波動率最高 30 檔 |

### Minervini 趨勢模板(第二階段上升趨勢)

1. 股價在 150 日、200 日均線之上
2. 150 日均線 > 200 日均線
3. 200 日均線至少上升 1 個月
4. 50 日均線在 150 日、200 日均線之上
5. 股價在 50 日均線之上
6. 股價比 52 週低點高 30% 以上
7. 股價距 52 週高點 25% 以內
8. 相對強度(RS)≥ 70。RS 是近 3/6/9/12 個月報酬加權(40/20/20/20%)後的全市場百分位

### VCP(波動收縮型態,`../strategies/vcp.py`,台股共用)

依 Minervini《超級績效》規則化:

- **底部**:起點 = 近 65 週最高價那天,底部長度 3~65 週
- **收縮**:從起點往右依序找「高點 → 之後最低 → 之後最高 → 之後最低…」,每段幅度 =(高 − 低)÷ 高;小於 2% 的回檔當雜訊
- 收縮 **2~4 次**,每次約前一次的**一半**(後 ÷ 前 介於 0.25~0.75)
- **總深度**(第一次收縮)10~35%
- **量縮**:最後一次收縮(從最後高點到今天)的平均量 < 50 日均量
- **樞紐點**:最後一次收縮的高點
- **買點**:隔天收盤突破樞紐點,且當天成交量 > 50 日均量 × 1.5(放量)
- **觀察名單**:已形成 VCP、股價在樞紐點下方 5% 內、還沒突破;「收縮」欄列出每次收縮幅度與底部週數

圖形判讀仍以人眼確認為準,參數集中在 `vcp.py` 開頭。

## 財報(SEC EDGAR)

用 SEC 的 XBRL frames API,一次抓「某項目、某一季」的全市場數值:淨利、營業利益、EPS、營收、股東權益。

- 多數公司第四季只在年報報全年 → 第四季 = 全年 − 前三季
- **ROE** = 近四季淨利 ÷ 股東權益;**營業利益成長率**、**營收年增率** = 單季年增
- **可用日期**:第一~三季 = 季底 + 45 天,第四季 = 季底 + 90 天(申報期限),避免回測偷看未來
- SEC 規定程式要在 User-Agent 附聯絡 email:存在 GitHub Secret `SEC_USER_AGENT`(格式 `名字 email`),程式碼裡沒有 email
- 沒設定時自動退回純價格版本(RSI、風險調整報酬拿掉財報條件,PEG 停用)
- 本機執行要先設環境變數:`set SEC_USER_AGENT=名字 email`(Windows)
