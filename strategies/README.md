# 策略選股 · 台股(免費資料,不需要任何帳號)

線上版(每個交易日 20:40 自動更新):https://peterpita-tech.github.io/Peterpita/strategies/

顯示每個策略的回測績效、權益曲線與**最新選股**。

| 策略 | 換股 | 選股 |
|---|---|---|
| 三頻率 RSI | 每週檢查 | RSI120>55、RSI60<75、RSI20 三日漲 >2%、RSI20>75 連 3 天、ROE>0;持有 60 天或跌破季線出場 |
| 低波動 30 | 每月 | 日均成交 >100 張中,60 日波動率最低 30 檔 |
| 風險調整報酬 前 15 | 每季 | ROE>5%、營收年增>0、3/6 月報酬為正,6 月報酬 ÷ 120 日波動 最高 15 檔 |
| 本益成長比 PEG | 每月營收公告後 | 營收 3/12 月均 >1.1、月增 >−10%,PEG 最低 10 檔,停損 10% |
| 高波動 30(對照組) | 每月 | 60 日波動率最高 30 檔,用來對照低波動異象 |

## 資料來源

| 資料 | 來源 | 什麼時候算「已知」 |
|---|---|---|
| 股價、成交量(還原權值) | Yahoo Finance | 當天收盤 |
| 月營收、年增率、產業別 | 公開資訊觀測站 月營收彙總表 | 次月 10 日 |
| ROE、營業利益成長率、EPS | 公開資訊觀測站 財報彙總表(上市 + 上櫃) | 季報公告期限(5/15、8/14、11/14、隔年 3/31) |

- 觀測站的損益表是年初累計值,程式會自動換算成單季。
- **ROE** = 近四季歸屬母公司淨利 ÷ 母公司權益(%)
- **營業利益成長率** = 單季營業利益年增率(%)
- **本益比** = 收盤價 ÷ 近四季 EPS
- 觀測站的歷史資料抓過就存在 `.cache/`。第一次執行約 20~30 分鐘,之後只補新月份、新季度。

## 回測規則(`backtest.py`)

- 換股日收盤後算訊號,**下一個交易日開盤價**成交,等權重
- 換股日之間買進持有;沒選到股票就空手
- 成本:買進收手續費 0.1425%,賣出收手續費 + 交易稅 0.3%(PEG 依原策略用手續費 3 折)
- 停損:收盤跌破進場價 ×(1 − 停損%)當天出場,下一個換股日才再進場
- 回測從 2019-01-01 開始,大盤基準為 0050(還原權值)

## 和 FinLab 版本的差異

- 資料來源、ROE 定義與回測細節不同,績效數字不會和 FinLab 完全一樣。
- 股票清單只有**目前**上市櫃的普通股,沒有已下市的股票(存活者偏差),回測績效會偏樂觀。

## 本機執行

```bash
pip install -r requirements.txt
python fetch_strategies.py      # → 策略選股.html(資料內嵌,直接雙擊開)
```

## 新增策略

在 `fetch_strategies.py` 寫一個回傳 `(position, 換股規則, 參數, 顯示指標)` 的函式,再加進 `STRATEGIES` 清單即可。

回測績效為歷史模擬,不代表未來報酬。
